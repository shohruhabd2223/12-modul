1-qadam

Model yoziladi

Model nima qiladi?

Model bazadagi jadvalni ifodalaydi. Bu yerda Book modeli yaratiladi va unda title, author, published_year maydonlari saqlanadi.

Bu qadamda biz ma’lumot qanday saqlanishini belgilaymiz.
models.py
Book modeli
from django.db import models

class Book(models.Model):
    title = models.CharField(max_length=200)
    author = models.CharField(max_length=120)
    published_year = models.IntegerField()

    def __str__(self):
        return self.title
2-qadam

Serializer yoziladi

Serializer nima qiladi?

Serializer modelni JSON ko‘rinishga o‘tkazadi va tashqaridan kelgan ma’lumotni tekshiradi. API yozishda bu eng muhim ko‘priklardan biri.

Ya’ni model bilan client orasida tartibli almashinuvni yaratadi.
serializers.py
BookSerializer
from rest_framework import serializers
from .models import Book

class BookSerializer(serializers.ModelSerializer):
    class Meta:
        model = Book
        fields = '__all__'
3-qadam va 4-qadam

ViewSet va Router

Endi API logikasi yoziladi. ModelViewSet CRUD amallarini tez beradi, DefaultRouter esa URL’larni avtomatik ochadi.

views.py 

from rest_framework import viewsets
from .models import Book
from .serializers import BookSerializer

class BookViewSet(viewsets.ModelViewSet):
    queryset = Book.objects.all()
    serializer_class = BookSerializer

urls.py 

from rest_framework.routers import DefaultRouter
from .views import BookViewSet

router = DefaultRouter()
router.register(r'', BookViewSet, basename='book')

urlpatterns = router.urls
Natija: endpoint ochilganda siz unga to‘g‘ridan-to‘g‘ri http://localhost:8000/ orqali murojaat qilasiz.

DRF-YASG BILAN ISHLATISH TARTIBI

Swagger’ni DRF loyihaga ulash bosqichlari

Bu dars uchun faqat drf-yasg yetarli. Quyida o‘rnatish, sozlash va ishlatish tartibi ketma-ket ko‘rsatilgan.

1-qadam

Kutubxonani o‘rnatish

pip install drf-yasg

Avval loyiha virtual environment ichida shu komandani ishga tushirasiz.

Qisqa tartib
1. drf-yasg ni install qiling.
2. Uni INSTALLED_APPS ga qo‘shing.
3. schema_view yarating.
4. /swagger/ url oching.
5. Brauzerda endpointlarni test qiling.

3-qadam
root/urls.py
from django.contrib import admin
from django.urls import path, re_path, include
from rest_framework import permissions
from drf_yasg.views import get_schema_view
from drf_yasg import openapi

schema_view = get_schema_view(
    openapi.Info(
        title="Student API",
        default_version='v1',
        description="Student CRUD API hujjati",
    ),
    public=True,
    permission_classes=[permissions.AllowAny],
)

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('app.urls')),
    re_path(r'^swagger(?P<format>\.json|\.yaml)$', schema_view.without_ui(cache_timeout=0), name='schema-json'),
    path('swagger/', schema_view.with_ui('swagger', cache_timeout=0), name='schema-swagger-ui'),
]
Qanday ochiladi?

Serverni ishga tushiring va brauzerda http://localhost:8000/swagger/ manzilini oching.

Qanday ishlatiladi?

Natija qayerda?

Pastki qismda response body, status code va serverdan qaytgan javob chiqadi.
