2-qadam · model 12–15 min

Product modelini front kartaga qarab tuzing

Mentor model yozishda har bir field oldida to‘xtasin: “Bu field frontendda qayerda ko‘rinadi?” degan savol darsni jonlantiradi.

class Product(models.Model):
    name = models.CharField(max_length=120)
    category = models.CharField(max_length=80)
    description = models.TextField()
    price = models.DecimalField(max_digits=12, decimal_places=2)
    old_price = models.DecimalField(max_digits=12, decimal_places=2, null=True, blank=True)
    rating = models.FloatField(default=0)
    image = models.ImageField(upload_to='products/', null=True, blank=True)
    is_popular = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)
Studentga ayting: modeldagi field nomi tushunarli bo‘lsa, serializer va frontend ulash ham osonlashadi.

Serializerni “modelni JSONga aylantiruvchi tarjimon” deb tushuntiring

Student serializer vazifasini yodlab emas, frontendga ketadigan JSON uchun kerakligini tushunsin. Model Python object, frontend esa JSON kutadi.

class ProductSerializer(serializers.ModelSerializer):
    class Meta:
        model = Product
        fields = [
            'id', 'name', 'category', 'description',
            'price', 'old_price', 'rating', 'image',
            'is_popular', 'created_at'
        ]

Search, filtering, ordering va paginationni frontend controls bilan bog‘lang

Studentga bularni alohida-alohida texnik termin sifatida emas, katalogdagi input, select va sahifa raqamlari sifatida ko‘rsating.

class ProductListAPIView(ListAPIView):
    queryset = Product.objects.all().order_by('-created_at')
    serializer_class = ProductSerializer
    filter_backends = [SearchFilter, DjangoFilterBackend, OrderingFilter]
    search_fields = ['name', 'description', 'category']
    filterset_fields = ['category', 'is_popular']
    ordering_fields = ['price', 'rating', 'created_at']
    pagination_class = ProductPagination
Teacher uchun urg‘u: query parameterlar frontend select/input o‘zgarganda URLga qo‘shiladi. Backend esa shu parametr bo‘yicha ma’lumotni qaytaradi.
