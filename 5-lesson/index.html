Authentication

“Sen kimsan?”

Server request yuborgan foydalanuvchini aniqlaydi: login qildimi, token yubordimi, request.user kim bo‘ladi?

Permission

“Senga nima mumkin?”

User tanilgach, endpoint unga qaysi amallarni ruxsat qilishini tekshiradi. Masalan GET hammaga, POST authenticated userga, DELETE esa admin userga.

Product modeli

Model nima qiladi?

Bu model bazadagi product jadvalini ifodalaydi. name, category, price, is_available va created_at maydonlari shu yerda saqlanadi.

Darsning qolgan qismi aynan shu Product modeli ustida quriladi.
models.py
from django.db import models

class Product(models.Model):
    name = models.CharField(max_length=200)
    category = models.CharField(max_length=100)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    is_available = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.name

Tushuntirish

AllowAny — public product list

  • Login bo‘lish shart emas
  • Product list endpointi uchun juda mos
  • Online shop katalogi ko‘pincha aynan public bo‘ladi
Natija: har kim GET /products/ ga kira oladi.
AllowAny
Public product list
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import AllowAny
from .models import Product
from .serializers import ProductSerializer

class ProductListPublicView(APIView):
    permission_classes = [AllowAny]

    def get(self, request):
        products = Product.objects.all()
        serializer = ProductSerializer(products, many=True)
        return Response(serializer.data)
IsAuthenticated
Faqat login qilgan user create qiladi
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated
from rest_framework import status
from .serializers import ProductSerializer

class ProductCreateView(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request):
        serializer = ProductSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
Tushuntirish

IsAuthenticated — protected create

  • request.user anonymous bo‘lmasligi kerak
  • Login qilmagan user POST qila olmaydi
  • Dashboard, admin panel yoki private actionlar uchun juda mos
Natija: POST /products/ faqat authenticated userlar uchun ochiladi.

Admin-only va mixed access

Delete uchun admin-only, list/create uchun mixed permission ko‘rsatish darsda eng tushunarli ketma-ketlik bo‘ladi.

IsAdminUser
Faqat admin delete qiladi
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAdminUser
from rest_framework import status
from .models import Product

class ProductDeleteView(APIView):
    permission_classes = [IsAdminUser]

    def delete(self, request, pk):
        product = Product.objects.get(pk=pk)
        product.delete()
        return Response({"message": "Product o‘chirildi"}, status=status.HTTP_204_NO_CONTENT)
IsAuthenticatedOrReadOnly
GET hammaga, POST authenticated
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticatedOrReadOnly
from rest_framework import status
from .models import Product
from .serializers import ProductSerializer

class ProductListCreateView(APIView):
    permission_classes = [IsAuthenticatedOrReadOnly]

    def get(self, request):
        products = Product.objects.all()
        serializer = ProductSerializer(products, many=True)
        return Response(serializer.data)

    def post(self, request):
        serializer = ProductSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
IsAdminUser qachon ishlatiladi?

Delete, stats, management va faqat staff user kiradigan endpointlarda ishlatiladi.

IsAuthenticatedOrReadOnly qachon qulay?

Productlar hammaga ko‘rinsin, lekin yangi product qo‘shish faqat login qilgan userga berilsin desangiz juda qulay.

STATUS KODLAR

200, 400 va 500 lik statuslar farqi

API javoblarida asosiy 3 ta katta guruhni ajratib tushuntirish juda foydali: 2xx muvaffaqiyat, 4xx client xatosi, 5xx server xatosi.

Client request
2xx 4xx 5xx
API response
2xx Success

Hammasi joyida

Request to‘g‘ri bordi va server muvaffaqiyatli javob qaytardi.

200 OK — list yoki detail muvaffaqiyatli olindi.
201 Created — yangi product muvaffaqiyatli yaratildi.
4xx Client Error

Muammo request tomonda

Server ishlayapti, lekin foydalanuvchi noto‘g‘ri ma’lumot yubordi yoki ruxsat yetmadi.

400 Bad Request — serializer xato topdi.
401 Unauthorized — user tanilmagan.
403 Forbidden — user tanilgan, lekin ruxsat yo‘q.
404 Not Found — object topilmadi.
5xx Server Error

Muammo server tomonda

Request to‘g‘ri bo‘lishi mumkin, lekin backendning o‘zida xatolik yuz berdi.

500 Internal Server Error — kod ichida kutilmagan xato.
503 Service Unavailable — server vaqtincha ishlamayapti.
