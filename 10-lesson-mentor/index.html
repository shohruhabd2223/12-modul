10-dars · takrorlash

DRF bo‘yicha o‘tilgan barcha mavzularni takrorlash darsi

Bu darsda yangi katta mavzu berilmaydi. Mentor o‘quvchilar bilan Swagger, CRUD endpointlar, generic views, ModelViewSet, searching, filtering, ordering, pagination, JWT token, login va register mavzularini qisqa savol-javob va amaliy mini topshiriqlar orqali qaytaradi.

Dars maqsadi

Mentor nimani tushuntiradi?

Asosiy vazifa
O‘quvchilar oldingi darslarda o‘rgangan DRF mavzularini bir-biriga bog‘lab tushunishi kerak: endpoint nima, view nima qiladi, serializer qayerda ishlaydi, Swaggerda qanday test qilinadi.
Dars formati
Ko‘p nazariya emas. Qisqa eslatma, savol-javob, keyin amaliy test: endpoint ochiladi, Swaggerda tekshiriladi, token bilan protected API ishlatiladi.
Takrorlanadigan mavzular

Qisqa checklist

Swagger
Endpointlarni ko‘rish va test qilish.
CRUD
Create, Read, Update, Delete endpointlar.
ListView / View
Oddiy view va ro‘yxat qaytaruvchi view farqi.
ListCreateView
GET list va POST create bir viewda.
ModelViewSet
CRUDni avtomatik yig‘ish.
Searching
?search= orqali qidirish.
Filtering
category, status kabi fieldlar bo‘yicha ajratish.
Ordering
price, date, rating bo‘yicha tartiblash.
Pagination
Ma’lumotlarni sahifalab qaytarish.
JWT Token
Access va refresh token bilan auth.
Login
Token olish va APIga yuborish.
Register
Yangi user yaratish endpointi.
Amaliy takrorlash

Darsda mentor ko‘rsatadigan endpointlar

GET/api/products/
List endpoint, pagination, search, filter va ordering bilan test qilinadi.
POST/api/products/
Create endpoint. ListCreateView yoki ModelViewSet orqali.
PUT/api/products/<id>/
Update endpoint. Bitta objectni o‘zgartirish.
DELETE/api/products/<id>/
Delete endpoint. Bitta objectni o‘chirish.
QUERY?search=&ordering=&page=
Searching, ordering va pagination birga qaytariladi.
AUTH/api/login/ · /api/register/
Login, register va JWT token olish takrorlanadi.
Mentor gapiradigan asosiy jumla: “Bugun yangi kod yodlamaymiz. Oldingi mavzularni bitta API loyihada qanday birga ishlashini ko‘ramiz.”

01

02

Endpointlar ochiladi va live test qilinadi.
03
CRUD amaliyot
GET, POST, PUT/PATCH, DELETE qaytariladi.
04
Auth tekshiruv
Register, login, token bilan request.
Tekshiruv mezoni

Dars oxirida o‘quvchi nimalarni bilishi kerak?

Minimal natija
O‘quvchi Swaggerda endpoint test qila oladi, CRUD endpointlar farqini biladi, ListCreateView va ModelViewSet nima uchun ishlatilishini tushuntira oladi.
Yaxshi natija
O‘quvchi searching, filtering, ordering, paginationni query orqali ishlata oladi, register/login qiladi va JWT token bilan protected endpointga request yubora oladi.
Takrorlash darsi uchun yakuniy savol:
“Bitta product API loyihada CRUD, search, filter, ordering, pagination va JWT auth qayerda ishlaydi?”
